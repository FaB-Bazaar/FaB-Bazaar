🃏 **FaB Card "Facet" Tags** — a searchable layer for *what a card actually does* (beyond class / type / keywords). Curated by hand, not auto-parsed from text. **v1 — 22 tags.**

🔧 **Mechanical** — what the card's text does
• `combo-enabler` — assembles a combo line (tutor / dig / order into the pieces)
• `combo-buff` — grants a bonus to cards with the **combo** keyword
• `chain-extender` — keeps the combat chain going (go again / play another)
• `pseudo-draw` — banish/reveal from your own deck to effectively draw
• `on-hit-payoff` — big effect that triggers only if the attack **hits**
• `disruption` — attacks the opponent's hand / arsenal / deck / board / abilities
• `tutor` — search your deck for a card
• `recursion` — return cards from graveyard / banish
• `cost-reduction` — discounts a future play (tempo)
• `evasive` — restricts how it can be defended (hard to block)
• `name-copy` — becomes another card's name (flexible combo glue)
• `scaling` — grows per copy / attacks hit / cards controlled

🎯 **Strategic** — how it's *used* (not written on the card)
• `beats-fatigue` — helps assemble an over-the-top turn past the opponent's block ceiling (NOT out-grinding them)
• `setup` — commit now for a deferred, conditional payoff
• `pitch-stack` — deliberately pitch to the **bottom** to order future draws / assemble a sequence
• `top-deck-order` — arrange the **top** of the deck (the mirror of pitch-stack)
• `key-turn` — one-shot ("destroy this" equipment) saved for the pivotal turn
• `density-dependent` — payoff scales with your deck's density of a card type

🔗 **Synergy** — named packages it plays with
• `gustwave`  • `wind`  • `vengeance`  • `combo-package`

🌀 **In action — Katsu (Tsunami) sample:**
• **Rushing River** → combo-enabler, chain-extender, pseudo-draw, top-deck-order, setup, wind
• **Break Tide** → on-hit-payoff, pseudo-draw, beats-fatigue, wind
• **Flood of Force** → combo-enabler, pseudo-draw, chain-extender, density-dependent, wind
• **Breeze Rider Boots** → chain-extender, combo-buff, beats-fatigue, key-turn

💡 **Why it matters:** these tags live in a table that joins to the card + printing data, so you can search by **function + identity + price** at once — e.g. *"Katsu's combo-enablers that beat fatigue, under $5"* (respecting class/talent legality — Katsu is an untalented ninja, so no draconic cards).
