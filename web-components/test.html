🧪 FaB Bazaar Web Components Test Page

Testing the React → Web Component conversion framework with three reference implementations.

1. Simple Component: <fab-callout>

Pattern: Props → Attributes only

Complexity: Low (no state, no composition)

View Code 
<fab-callout
  title="New to Dromai?"
  text="This guide assumes basic hero knowledge..."
  link-href="#"
  link-text="View Beginner's Guide">
</fab-callout>

2. Moderate Component: <fab-creator-spotlight>

Pattern: Props → Attributes + Composition (dual mode)

Complexity: Medium (supports both attribute mode and slot mode)

Attribute Mode (Simple)

View Code (Attribute Mode) 
<fab-creator-spotlight
  image-url="https://via.placeholder.com/150"
  name="Tournament Champion"
  bio="Top 8 at multiple majors..."
  links='[{"href":"#","label":"Patreon","icon":"patreon"}]'>
</fab-creator-spotlight>

Slot Mode (Advanced)

Custom Content Creator

This is custom HTML content in the header slot. You can use any formatting you want here.

Custom Link 1 Custom Link 2
View Code (Slot Mode) 
<fab-creator-spotlight image-url="...">
  <div slot="header">
    <h3>Custom Content Creator</h3>
    <p>This is <strong>custom HTML</strong>...</p>
  </div>
  <div slot="links">
    <a href="#">Link 1</a>
  </div>
</fab-creator-spotlight>

3. Complex Component: <fab-spotlight-card>

Pattern: Client-side data fetching + State management

Complexity: High (fetches data, loading states, error handling, card mention parsing)

⚠️ Note: This component requires a live API endpoint. It will show an error in this test page.

View Code 
<fab-spotlight-card
  printing-id="WTR001"
  title="Round 1 MVP"
  commentary="This card was crucial. **Fyendal's Spring Tunic** enabled...">
</fab-spotlight-card>
Commentary Syntax

Wrap card names in **double asterisks** to render them as highlighted mentions:

commentary="Regular text **Highlighted Card Name** more text"
